# freeai
> Mapa das opções gratuitas para codar com IA — harnesses de CLI e IDE, provedores com free tier e modelos open-weights, em tabelas comparativas com limites reais e links oficiais.
> goal: none
> spec: none

## Overview

Repo docs-only, público, PT-BR. Cada tabela carrega o carimbo "verificado em <mês/ano>" e um link oficial por linha — free tier muda todo mês, então a data importa mais que o número. O ritmo é revisão mensal dos limites (ver ROADMAP).
