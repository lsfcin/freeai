# Extensões de IDE
> verificado em ago/2026 — extensão BYO key é grátis por definição; a conta chega do provedor de modelo. Aponte para um free tier de [provedores.md](provedores.md) e o conjunto fica zero-real.

| Extensão | Licença | Como fica grátis | Modelos | Link |
|----------|---------|------------------|---------|------|
| Cline | Apache 2.0 | BYO key → grátis com free tier (OpenRouter, Groq, AI Studio…) | qualquer provedor suportado | [github.com/cline/cline](https://github.com/cline/cline) |
| Roo Code | Apache 2.0 | BYO key, mesmo jogo do Cline (é fork dele) | vários; modos especializados (architect, debug, orchestrator) | [roocode.com](https://roocode.com) |
| Kilo Code | FOSS | BYO key; superset do Cline + Roo | vários | [kilocode.ai](https://kilocode.ai) |
| Continue | Apache 2.0 | BYO key **ou modelos locais** (Ollama) — o único 100% offline da lista | local ou nuvem | [continue.dev](https://continue.dev) |
| GitHub Copilot | proprietário | **Copilot Free**: 2.000 completions/mês + cota de chat (GitHub AI Credits); modelo por auto-seleção, sem escolher qual | GitHub AI | [docs.github.com/copilot](https://docs.github.com/en/copilot/get-started/plans) |

Regra prática: se você já tem conta GitHub, o Copilot Free resolve o dia a dia sem configurar nada. Se quer escolher modelo e pagar zero, Cline/Roo/Kilo + OpenRouter `:free` ou Groq.
